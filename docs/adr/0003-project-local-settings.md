# リポジトリごとに Jev Auto Mode の設定を上書きできる

ユーザー共通設定に加え、信頼するリポジトリの `.omp/jev-auto-mode.json` を読み込む。プロジェクト設定は同名のユーザー設定を上書きし、未指定の値はユーザー設定を引き継ぐ。プロジェクト内の `/jev-auto-mode` 操作は、プロジェクト設定ファイルが既にある場合そこへ保存する。プロジェクト設定はゲートを無効化できるため、利用するリポジトリをユーザーが信頼していることを前提とする。APIキーはユーザー共通領域に保存する。

コマンドからの保存は、その保存先に既に指定された値を保持し、変更した項目だけを更新する。閾値のリセットは現在の保存先の上書きを削除する操作とし、プロジェクトでは共通設定を、共通設定にも指定がなければ標準値を直ちに継承する。保存時にリポジトリ外を指すリンクとリンク切れを拒否し、別ファイルの上書きや共通設定への意図しない保存を防ぐ。
