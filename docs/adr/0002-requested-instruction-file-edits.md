# 依頼された指示ファイルの変更を保存先だけで拒否しない

指示ファイルの保護は、依頼外の変更を防ぐためのものとする。ユーザーが依頼した指示変更は、禁止事項の削除を含めて許可対象とし、保存先が指示ファイルであることだけでは拒否せず、一律の追加確認も求めない。秘密の外部送信など、操作に伴う独立した危険判定は維持する。

依頼の範囲は会話の流れを含めて判断する。通常の作業として指示ファイルの更新が自然に含まれる場合、ファイル名や変更内容をユーザーが個別に指定していなくても進めてよい。指示ファイルであることを理由に追加確認を増やさず、会話から変更目的を判断できない場合だけ通常の編集と同じように確認する。
