# 実行確認の通知

Jev がコマンド実行の確認画面を開くとき、Herdr の既存連携イベント `herdr:blocked` に `active: true` と固定文言「Jev: コマンド実行の確認待ち」を渡す。通知にコマンド本文は含めない。

Yes、No、キャンセル、画面の例外終了のいずれでも、`finally` で `active: false` を渡す。Herdr は入力待ちを参照数で管理するため、開始と解除を必ず対応させる。

対象はコマンド実行の確認画面に限定し、設定画面には通知を追加しない。承認の結果や危険判定は変更しない。Herdr の連携拡張がない場合、イベントの受信者がいないため何も起こらない。

OMP 共通 UI を変更せずに今回の確認待ちを通知できるため、Jev から既存の連携口を利用する。実際の通知音や配信は Herdr 側で扱う。
